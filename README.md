### About

I'm a full stack developer at [**Immoviasoft**](https://immoviasoft.com), based in Lomé, Togo.
I design and ship web applications end to end — from the database and the API to the interface.

- **Backend** — Laravel, Express.js, REST APIs, MySQL / PostgreSQL
- **Frontend** — React, Next.js, TypeScript, Tailwind CSS
- **Workflow** — Debian user, Docker, Git, shell scripting and small CLI tools to automate my daily work

- Open to freelance missions and collaborations
